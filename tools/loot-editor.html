Change what spawns on your private server

  1. Quit DayZ so the server isn't running. Changes apply the next time you launch.
  2. Click Open mission folder and pick your mission folder. Loot Editor.bat copies its path to the clipboard, so you can paste it into the folder picker's address bar. It's usually …\steamapps\common\DayZServer\mpmissions\dayzOffline.chernarusplus.
  3. Edit values, then click Save changes. The first save of each file keeps the original next to it as <file>.dayzsolo-backup.

Opening the folder needs Edge or Chrome. In other browsers use Open XML files…: pick types.xml, globals.xml and events.xml from the mission's db folder, and saving downloads the edited files for you to copy back.

Steam updates to DayZ Server can overwrite these files. Your backups and edits are plain XML, so keep a copy of anything you've tuned.
