Join a friend

      

      

      

        No invite code? Enter the details by hand
        

          

          

          

        

        
Without a code DayZ Solo loads the same mods you would load yourself, so they must match your friend's.

      

      

      

    


    

      
How your friends reach you

      
    
        
  • Tailscale (easiest, free): everyone installs Tailscale and signs in. Invite your friends to your tailnet, or share this PC with them from the Tailscale admin page. DayZ Solo then offers your 100.x.x.x address automatically. No router changes.
    • 
        
  • ZeroTier: create a network at my.zerotier.com, everyone joins it with the network ID, and you tick "Auth" for each member. Pick the ZeroTier address above.
    • 
        
  • Port forwarding: in your router, forward UDP ports 2302-2305 to this PC's home-network address, then press Use my public IP. Works without extra software, but shows your public IP to your friends.
    • 
        
  • Same house: pick the home-network address.
    • 
      

      
Press Allow through Windows Firewall once on the host PC. Everyone needs DayZ, the same DayZ Solo version and the same mods; the invite code lists the mods and the Join button tells your friends what they're missing. Voice chat is on in co-op. The server keeps running while friends play, even after you quit.

    

  


  

    

      
      
      
      
      
      
    

    

  


  

    

      

        
Mods

        
        
        
        

      

      
Subscribed Workshop mods load automatically, in dependency order. Untick a mod to leave it out. Changes save by themselves and apply the next time the server starts.

      

      
    
      
    
        
        
      
    
      
    Loading…
    
      
      
      
      Resubscribe (like DZSA) unsubscribes, lets Steam delete the mod and downloads a fresh copy: the fix for a mod that is broken, half-updated or gets you kicked. Steam must be running; updating and resubscribing need the server stopped and DayZ closed.
      
    
      
    
      
      
      
        
      Mod settings files
      
        
        
      
      
      
      Settings files mods keep in the server profile, such as QoL\Mining.json, QoL\ATM.json or Expansion's settings. Most mods write theirs on their first start. Stop the server before saving; the first save keeps the original as .dayzsolo-backup.

      Categories
      
        
        
      
      
      
      
        
      
          
      OrderName in the shopBase priceTrader pays %ItemsShow
      
          
        
      
      
      
      
      Base price is what an average item in that category costs; with rarity on, common items cost 0.6x and rare ones up to 3x. An empty "Trader pays %" uses the shop-wide value. Items keep their base price when you move them to another category. Your own categories start empty: move items into them below.

      ItemCategoryBuySellOptionsShow

      QoL Mining
      
      
      
        
      
      
      
      
      Mining only runs while the server runs, so in solo it counts your playing time. The mod's default is 480 (8 hours); DayZ Solo uses 120. Sell mined Bitcoin at an ATM for cash, then PAY IN at the shop. Bitcoin is hidden from the shop itself unless you show it in the item list.
